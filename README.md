# 🤖 AI SQL Assistant

An AI-powered SQL Assistant that allows users to interact with a database using natural language.

Instead of manually writing SQL queries, users can simply ask questions such as:

> "Show all customers from Pune"

The system converts the natural language question into SQL, executes the query, displays the results, and provides an AI-based explanation of the generated SQL.

---

## 🚀 Features

- 🧠 Natural Language to SQL
- ⚡ AI-powered SQL Query Generation
- 🗄️ SQLite Database Integration
- ▶️ Execute SQL Queries
- 📊 Display Query Results in Tables
- 💡 AI SQL Explanation
- 🔧 SQL Error Handling
- 🔍 Database Schema Viewer
- 🕒 Query History
- 🎨 Modern Animated User Interface
- 📱 Responsive Design
- 🛡️ Safe SQL Generation with SELECT-focused queries
